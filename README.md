# NIH women's health research funding, FY2013–2026

This repository holds the annotated R code and de-identified replication data for two companion brief reports on NIH women's health research funding.

| Folder | Report |
|---|---|
| [`nih-womens-cv-funding/`](nih-womens-cv-funding/) | Women's cardiovascular research funding at NIH |
| [`nih-womens-health-funding-topics/`](nih-womens-health-funding-topics/) | NIH women's health research funding across major areas of need |

Each folder is self-contained: open it and run `Rscript R/run_all.R` from that folder. See each folder's README and `data/README.md` for details. Data are from NIH RePORTER (public domain); FY2026 is incomplete.
